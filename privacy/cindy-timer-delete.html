Cindy Timer 데이터 삭제 요청

앱 Cindy Timer · 크로스핏 AMRAP · 개발자 rabratory · 앱 ID com.cindytimer.app

1. 앱을 지우면 끝나는 것

운동 기록(시작 시각, 경과 시간, 라운드별 시각과 간격, 설정값)은 기기 안에만 있습니다. 앱을 삭제하면 그 자리에서 함께 지워지며, 저희가 따로 보관하는 사본은 없습니다. 계정이나 로그인이 없어 기록을 사용자와 연결할 방법 자체가 없습니다.

2. 삭제를 요청하는 방법

  1. rabratory@gmail.com 으로 메일을 보냅니다.
  2. 제목에 “Cindy Timer 데이터 삭제 요청” 이라고 적습니다.
  3. 본문에 앱 인스턴스 ID 를 적어 주시면 대상을 특정할 수 있습니다. 설정 화면 맨 아래 의견 보내기 를 누르면 기기·버전 정보가 자동으로 채워지므로, 그 내용을 함께 보내 주셔도 됩니다.
  4. 영업일 기준 30일 안에 처리하고 회신합니다.

3. 삭제되는 데이터

  • Firebase Crashlytics 의 비정상 종료 로그
  • Google Analytics for Firebase 의 사용 통계와 앱 인스턴스 식별자
  • 해당 기기에 연결된 AdMob 광고 식별자 기반 데이터

4. 보관되는 데이터와 기간

개인을 식별할 수 없도록 집계된 통계(예: 국가별 세션 수)는 삭제 요청 이후에도 남을 수 있습니다. Google 측 원본 로그는 각 서비스의 기본 보관 정책(최대 14개월)에 따라 자동으로 만료됩니다.

5. 직접 할 수 있는 것

  • 광고 ID 재설정·삭제 — 기기 설정 → Google → 광고
  • EEA·영국·스위스 사용자 — 앱 설정의 “개인정보 옵션”에서 광고 동의를 언제든 철회
  • 기록 백업 — 설정 → 기록 내보내기 · 가져오기 로 삭제 전에 파일로 뺄 수 있습니다

Cindy Timer Data Deletion Request

App Cindy Timer · CrossFit AMRAP · Developer rabratory · App ID com.cindytimer.app

1. What uninstalling already removes

Your workout records (start time, elapsed time, per-round timestamps and intervals, settings) live only on your device. Uninstalling the app deletes them, and we keep no copy. There is no account or sign-in, so there is no way to tie those records to you in the first place.

2. How to request deletion

  1. Email rabratory@gmail.com.
  2. Use the subject “Cindy Timer data deletion request”.
  3. Include your app instance ID so we can identify the records. Tapping Send feedback at the bottom of Settings fills in your device and app version automatically — sending that along works too.
  4. We process the request and reply within 30 days.

3. Data that is deleted

  • Crash logs in Firebase Crashlytics
  • Usage statistics and the app-instance identifier in Google Analytics for Firebase
  • AdMob advertising-identifier data tied to that device

4. Data that is retained, and for how long

Aggregated statistics that cannot identify an individual (for example, session counts per country) may remain after a deletion request. Raw logs on Google's side expire automatically under each service's default retention policy, up to 14 months.

5. What you can do yourself

  • Reset or delete your advertising ID — device Settings → Google → Ads
  • EEA, UK and Switzerland — withdraw ad consent at any time under "Privacy options" in the app's Settings
  • Back up your records — Settings → Export · Import writes everything to one file before you delete
